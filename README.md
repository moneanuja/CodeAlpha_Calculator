Basic Calculator

Project Overview:
This project is a Basic Calculator built using HTML, CSS, and JavaScript.
It performs basic arithmetic operations and provides a simple, user-friendly interface.

Features:
Addition (+), Subtraction (−), Multiplication (×), Division (÷)
Clear screen functionality
Real-time display of input and result
Responsive calculator UI
Keyboard support (Bonus)
Modern styling with CSS

Technologies Used:
HTML — Structure of the calculator
CSS — Styling and layout
JavaScript — Calculator logic and interactions

How It Works:
User clicks calculator buttons or uses keyboard input.
Numbers and operators appear on the display screen.
The calculator processes the expression.
Press = to get the result.
Press C to clear the screen.

Future Enhancements:
- Dark mode
- Scientific calculator functions
- Calculation history
- Better animations

Output:
The calculator provides accurate results for basic arithmetic calculations with an interactive user interface.
